Падение при загрузке ауры ДК
==========================

Исследован дамп worldserver от 27.11.2026 16:00:47. Образ сервера совпадает
со сборкой №19 по PE timestamp (0x6b097870) и SizeOfImage (0x28f9000).

Исключение C0000005: чтение адреса 0x4c в Spell::Spell, RVA 0x111706a.
В конструктор передан нулевой caster. По машинному коду вызывающего обработчика
(RVA 0xa73de0) установлена случайная генерация ID 58208–58223 и вызов
GetCaster()->CastSpell без проверки. Это HandleEffectApply скрипта
spell_lich_king_vo_blocker (аура 58207), zone_the_scarlet_enclave.cpp.

Нижние кадры стека соответствуют восстановлению аур игрока из БД,
Player::LoadFromDB и загрузке Playerbot. При восстановлении сохранённой ауры
её исходный кастер может отсутствовать. Обработчик продолжал вызов с nullptr.

Исправление проверяет кастера один раз перед вызовом. Если его нет,
пропускается только разовое произнесение шёпота. Сама аура и данные персонажа
сохраняются. При доступном кастере старое поведение остаётся.

Патч применяется к зафиксированному исходнику ядра при подготовке сборки.
Регрессионный тест компилирует обработчик из исходного фрагмента после
применения патча: игрок без кастера, игрок с кастером, цель не игрок,
самостоятельный каст. Полная сборка и проверка в игре учитываются отдельно.

Дополнительно обновление теперь содержит активный auction_market.conf.
Установщик сохраняет существующий пользовательский конфиг. Отсутствие этого
файла в сборке №19 не является причиной исследованного падения.
