Экипировка случайных ботов по этапам
===================================

Настройка находится в Server/configs/modules/bot_gear_progression.conf:

```ini
BotGearProgression.Stage = 8
BotGearProgression.CurrentTierRaidSize = 10
BotGearProgression.CurrentTierHeroic = 0
BotGearProgression.CurrentTierHardModes = 0
BotGearProgression.RerollOnStartup = 1
```

При Stage = 8 выдаются предметы из источников не позднее Каражана, Груула
и Магтеридона, включая предыдущий контент и первый сезон арены.
Это каталог конкретных источников предметов, а не скрытый предел ilvl.
У одного предмета может быть несколько источников. Достаточно одного
источника, который проходит все ограничения одновременно.

| Значение | Последний доступный контент |
| --- | --- |
| -1 | Ограничение и стартовая переэкипировка выключены |
| 0 | Подземелья Classic, Огненные Недра, Ониксия |
| 1 | Логово Крыла Тьмы |
| 3 | Зул'Гуруб |
| 5 | Ан'Кираж |
| 6 | Наксрамас 40 |
| 8 | Подземелья и героики TBC, Каражан, Груул, Магтеридон, S1 |
| 9 | Змеиное святилище, Крепость Бурь, S2 |
| 10 | Хиджал, Чёрный храм, S3 |
| 11 | Зул'Аман и его награды за значки |
| 12 | Солнечный Колодец, Терраса Магистров, поздние значки TBC, S4 |
| 13 | Подземелья WotLK, Наксрамас, ОС, Око Вечности, S5 |
| 14 | Ульдуар, S6 |
| 15 | Испытание крестоносца/чемпиона, Ониксия 80, S7 |
| 16 | ЦЛК и его подземелья, S8 |
| 17 | Рубиновое святилище |

Нумерация ориентирована на Individual Progression; состояние самого IP
не меняется. Промежуточные 2/4/7 соответствуют 1/3/6 по доступным вещам.
В отличие от IP здесь 11 используется для отдельного открытия Зул'Амана.

Размер и сложность текущего этапа
---------------------------------

Для WotLK отдельно проверяются размер рейда, героическая сложность и хардмоды:

```ini
BotGearProgression.Stage = 13
BotGearProgression.CurrentTierRaidSize = 10
BotGearProgression.CurrentTierHeroic = 0
BotGearProgression.CurrentTierHardModes = 0
```

Это Наксрамас/ОС/Око Вечности на 10 игроков без бонусного лута за драконов
Сартариона. У Наксрамаса и Ока Вечности нет отдельной героической сложности.
Вещи Наксрамаса-25 не проходят только от включения Heroic: для них нужен размер 25.

RaidSize = 25 допускает и 10, и 25 игроков. Heroic = 1 добавляет героические
версии выбранного размера для ИК, ЦЛК и РС. HardModes = 1 независимо открывает
бонусный лут Сартариона, хардмоды Ульдуара и Алгалона. Героические подземелья
на 5 игроков этими настройками не ограничиваются. Classic/TBC также не затрагиваются.

Размер и сложность ограничивают только источники ТЕКУЩЕГО этапа. На этапе 14
с размером 10 Наксрамас-25 доступен, Ульдуар-25 недоступен. На этапе 17/10/normal
доступен весь предыдущий ЦЛК, в том числе 25 heroic; РС остаётся ограничен 10 normal.
Более поздние этапы недоступны при любых значениях остальных параметров.

Улучшенные T9/T10 учитывают альтернативные пути получения: промежуточная версия
через жетон из 25 normal ИЛИ 10 heroic, высшая версия — через 25 heroic.
Базовые версии за значки — отдельный источник. У T7/T8 учитывается размер
рейда для конкретной версии комплекта. Источник не заменяется сравнением ilvl.

Старый активный конфиг сохраняется установщиком. Если новых строк в нём нет,
используются значения 10/normal/без хардмодов. Для 25/heroic добавьте строки явно.

Как проходит переэкипировка
--------------------------

Каждый случайный бот один раз за процесс worldserver проходит штатный
clear + autogear по своей текущей специализации. Переодеваются именно вещи;
уровень, таланты, профессии и квесты этим модулем не рандомизируются.
Проверка выполняется при первом входе бота после запуска, в том числе если
бот вошёл значительно позже остальных. Повторный вход в том же процессе
не запускает второй раунд. На уровнях 1–4 сохраняется штатный стартовый комплект.

Обработка распределена во времени: по умолчанию один бот каждые 200 мс.
Бой, смерть, полёт, телепортация, очередь БГ и само БГ откладывают обработку.
Снаряжение обычных случайных ботов заменяется с удалением прежнего комплекта,
как при штатной полной переэкипировке. Поэтому переполненные сумки не мешают
снижению этапа. Личные аккаунты не обрабатываются.

Защита от замены и от ограничений этого модуля:

- Бот присутствует в списке друзей персонажа на реальном аккаунте. Друзья
  других автоматических ботов такой защиты не дают. Списки читаются при запуске.
- Бот состоит в гильдии, глава которой находится на реальном аккаунте.
  Используется штатный кеш Playerbots. Само членство в гильдии ботов не защищает.
  Если руководство бывшей гильдии игрока передано случайному боту, штатный
  критерий считает её гильдией ботов; исторический создатель в БД не хранится.

При включённом этапе RandomGearScoreLimit перестаёт ограничивать обычную
автоматическую выдачу: достаточно менять один Stage. Ручной autogear с явно
заданным ilvl может дополнительно ограничить подбор. Фильтр источников
проверяется до заполнения пула кандидатов и при окончательной проверке
надевания, включая PvP-аксессуар. Поиск умеет опускаться к более низким уровням
требований: бот 80 уровня на этапе T4 может получить вещи для 70 уровня.

Границы каталога
---------------

WotLK: исходный AtlasLoot 5.11.04 от 7 августа 2010 года,
репозиторий nanderson11/AtlasLootEnhanced, коммит
092b7fcf14f0529dd54baebcb7118c8e53136d48, лицензия GPLv2.

Classic/TBC (включая восстановленный IP Наксрамас 40) и вспомогательные
данные ремесла: Hoizame/AtlasLootClassic,
8e99341e4e779328460bf7684c0d5b22ce50ddf1. Его таблицы рейдов и подземелий
WotLK не используются: в них есть переносы лута из более позднего Classic.

В каталоге 16 140 предметов и 17 091 отдельный источник. CSV содержит
item, stage, raid_size, heroic, hard_mode, source. Одному предмету соответствует
несколько строк, если его можно получить разными способами. Ограничиваются
только оружие и броня; рубашка и табард исключены. Это не ограничение аукциона.

Неизвестные предметы при активном Stage не выдаются. Для ремесла, у которого
не установлен ранний источник рецепта, используется последний этап дополнения.
Это может исключить некоторые действительно ранние ремесленные вещи; такой
каталог намеренно не обещает полного исторического восстановления каждого патча.
Для большинства квестовых и случайных зелёных вещей источник также может
отсутствовать. В спорном случае добавляется точная запись, а не порог ilvl.
Чары, камни, расходники и профессии остаются под штатными правилами Playerbots;
данный этап ограничивает исходные предметы оружия и брони.

Точечные поправки без перекомпиляции:

```ini
BotGearProgression.ItemOverrides = "28770:8,32471:10"
```

Формат: ID предмета:первый этап. Значение 99 запрещает конкретный предмет.
Это явное исключение без ограничения размера/сложности; оно может разрешить
вещь, которую обычный каталог блокирует. Для исправлений режима предпочтительно
менять источник в каталоге, а не добавлять такое исключение.
CSV data/bot-gear-catalog.csv содержит все записи и их источники. Скрипт
scripts/generate-gear-catalog.py воспроизводит каталог из двух указанных checkout
(сначала AtlasLoot 5.11.04, затем AtlasLootClassic) с lupa 2.8. Обычная сборка использует готовый GearCatalog.inc.

Изменение Stage через reload config меняет последующие проверки подбора;
полный очередной раунд переэкипировки происходит после перезапуска worldserver.
В Playerbots.log пишутся выбранный этап, защищённые боты и результаты обработки.

Сохранность существующего bot_gear_progression.conf обеспечивает установщик.
Автотесты проверяют границы источников, 10/25/heroic/хардмоды, альтернативные
жетоны T9/T10, отсутствие лута Classic в оригинальных героиках, неизвестные предметы,
один раунд за запуск, друзей, два вида гильдий, отложенную обработку и отключение.
Проверка в игре после сборки остаётся отдельным этапом.
