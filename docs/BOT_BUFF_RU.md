# Баффы от выделенного бота — BotBuff 0.1.0

Серверное расширение Playerbots: команда `.botbuff` просит выделенного бота
наложить подходящие одиночные заклинания на персонажа, подавшего команду.
Приглашение в группу, аддон или изменение хозяина бота не нужны.

Исходники включены в ту же ветку feature/group-builder поверх общей сборки с
гардеробом и бестиарием. Пока сервер с этой функцией не скомпилирован, команды
в установленном EXE нет. Текущая сборка бестиария этим изменением не затрагивается.
Новых конфигов и SQL нет; после следующей общей сборки применяется обычный
установщик обновления, сохраняющий активные конфиги.

## Макрос

Выделить бота и нажать макрос:

```
/s .botbuff
```

Сервер распознаёт точечную команду до отправки сообщения в общий чат.
Остаться рядом на несколько секунд. Дальность запроса — 30 метров, нужна
прямая видимость. Если бот верхом, он спешится; полёт на такси не прерывается.

Для определённого благословения паладина:

```
/s .botbuff might
```

Поддерживаются `kings`, `might`, `wisdom`, `sanctuary`. Автоматический выбор
предпочитает королей, если они изучены; иначе — мудрость для персонажа с маной
или могущество без маны. Если короли уже даны другим паладином, пробует
следующее полезное изученное благословение. Один паладин накладывает одно своё благословение,
а не перебивает его остальными. Автоматический режим сохраняет уже имеющееся
благословение этого паладина; явное имя позволяет попросить другое.

## Что накладывается

| Класс | Одиночные баффы |
|---|---|
| Маг | Интеллект |
| Жрец | Стойкость, дух, защита от тёмной магии — если изучены |
| Друид | Знак дикой природы и шипы |
| Паладин | Одно выбранное благословение |
| Чернокнижник | Подводное дыхание |

Боевые кулдауны, ограниченные защитные эффекты и заклинания с неприятными
побочными действиями не включены. Групповые крики, тотемы и ауры не превращаются
в одиночные баффы: если класс не имеет подходящего заклинания, команда сообщит об этом.

Используются только изученные активные заклинания. Нормальные проверки заклинаний
подбирают допустимый ранг и учитывают ману, реагенты, ГКД и ограничения цели.
Равный/более высокий ранг и уже действующая групповая версия сохраняются.
Команда не создаёт ауру напрямую и не применяет бесплатный triggered cast.

## Ограничения и проверка

- Оба персонажа живы, вне боя, не на БГ/арене, не в дуэли или перелёте.
  Бота в очереди БГ/арены/LFG команда не отвлекает.
- Бот должен быть дружественным, на той же карте/фазе. Управляемый другим
  реальным игроком бот не отвлекается. Реальные игроки не управляются командой.
- Повторный запрос от одного игрока — не чаще раза в пять секунд. У одного бота
  одна активная просьба; общий лимит — 32. Максимальное ожидание — 20 секунд.
- Заклинания выполняются в обновлении карты самого бота с паузами на ГКД.
  При отсутствии запросов остаётся только дешёвая проверка атомарного флага.
  Бой, уход, телепортация или выход из игры прекращают запрос. Состав группы,
  хозяин и стратегии бота не переписываются.

Автоматические проверки используют настоящие функции выбора рангов, защиты
существующих аур и шага очереди с подставным игровым окружением. Полная серверная
компиляция и игровые проверки ещё не выполнены.

Первый тест: свободный паладин вне группы → макрос → одно благословение;
повторить без необходимости обновления; затем явно попросить другое. После этого
проверить мага/жреца, низкоуровневого получателя, дистанцию и начало боя.
