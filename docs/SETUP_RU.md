# Первый запуск

Новая установка: используйте отдельный каталог и новые базы данных.
Клиент — WoW 3.3.5a build 12340. Новых рас и обязательного MPQ-патча в рецепте нет.

## 1. MySQL

Установите MySQL 8.x x64 и запустите службу на локальном порту 3306.
Создайте базы acore_auth, acore_world, acore_characters, acore_playerbots
с кодировкой utf8mb4 и пользователя с правами на эти четыре базы.
Нужны права создавать таблицы, обновлять схему и читать/записывать данные.
Служба MySQL не входит в артефакт; mysql.exe нужен обновлятору базы.

## 2. Конфиги

Из каталога Server запустите PowerShell:

```powershell
./configure-local.ps1 -DatabasePassword 'ВАШ_ПАРОЛЬ' -Bots 500
```

Если пользователь базы отличается от acore, добавьте -DatabaseUser 'ИМЯ'.
Пароль не должен содержать точку с запятой, двойные кавычки и переводы строк.
Пароль сохраняется в локальных конфигурационных файлах; не публикуйте их.
Скрипт выставляет EnablePlayerSettings = 1 и DBC.EnforceItemAttributes = 0.
При повторном запуске обновляет перечисленные параметры, сохраняя прочие настройки.

## 3. Данные клиента

Извлеките dbc, maps, vmaps и mmaps инструментами из сборки в Server/Data.
Инструменты запускаются из каталога клиента. mmaps важны для передвижения ботов.
Не используйте файлы данных от другой версии игры.

## 4. База и сервер

Сначала запустите start-authserver.bat, затем start-worldserver.bat.
При первом старте сервер импортирует SQL из Server/Source.
Первое создание сотен ботов занимает время; следите за консолью и логами.

В acore_auth.realmlist нужен realm с ID 1 и адресом 127.0.0.1.
Если строки нет, создайте её через MySQL с именем сервера и портом 8085.
Команды консоли worldserver для своего аккаунта:

```text
account create ИМЯ ПАРОЛЬ
account set gmlevel ИМЯ 3 -1
```

В клиентском realmlist.wtf установите set realmlist 127.0.0.1.

## 5. Модули

- Playerbots: 500 ботов, штатный диапазон уровней. Для управления можно установить MultiBot.
- Individual Progression включён; optional SQL и MPQ автоматически не применяются.
- Portal Master (entry 190000) размещается SQL в столицах. Перенос всей группы
  ботов пока не проверен. Ограничения прогрессии действуют через hook телепортаций.
- Reforging: поставьте NPC командой .npc add 200004. Проверьте характеристики после
  перековки, смены экипировки и повторного входа вместе с Individual Progression.
- Transmog: configs/modules/transmog.conf; ID NPC указан в SQL модуля в Source/modules.
- AHBot: создайте отдельный аккаунт и персонажа для аукциона, укажите их реальные ID
  в configs/modules/mod_ahbot.conf, включите продавца/покупателя и настройте квоты
  mod_auctionhousebot по README модуля. Пока это не выполнено, аукцион не настроен.
- Арена 1×1 не включена: участие Playerbots в её очереди не подтверждено.

## Границы проверки

Успешный Actions-run подтверждает компиляцию и загрузку EXE с --version.
Полный запуск мира, импорт SQL и совместную работу модулей нужно проверить в игре.
Для диагностики сохраните первый лог worldserver и точный текст ошибки.
