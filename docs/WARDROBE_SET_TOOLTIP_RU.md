# AC Wardrobe 0.1.1 — счётчик частей комплекта

Клиентский hotfix поверх гардероба 0.1.0. Пересборка сервера не нужна.

Старый mod-transmog меняет PLAYER_VISIBLE_ITEM_* на ID предмета-облика.
Клиент 3.3.5 использует их для подсчёта частей сета в подсказке. Настоящий
предмет остаётся надетым: AddItemsSetItem в ядре считает бонус по ItemTemplate
надетой вещи, а не по видимому ID. Этот патч не меняет предметы или бонусы.

Аддон пересчитывает счётчик и подсветку списка по GetInventoryItemLink игрока.
При изменении счётчика обновляет обычные серые/зелёные строки порогов бонуса.
Красные ограничения (в том числе профессия) сохраняются. Окно осмотра другого
игрока пропускается. При неполном кэше предметов подсказка остаётся нетронутой.
Исправление рассчитано на стандартный список всех частей в подсказке 3.3.5;
другие аддоны, полностью заменяющие подсказку, могут потребовать адаптации.

## Установка

1. Закрыть клиент или выйти к выбору персонажей.
2. Скопировать `Interface/AddOns/ACWardrobe` из архива в папку игры с заменой
   файлов. Старую папку WTF и сохранённые наряды не удалять.
3. Войти в игру. Серверные EXE, конфиги и SQL менять не нужно.

## Проверка

Навести на настоящую часть комплекта, записать счётчик. Изменить облик
наплечников на предмет другого комплекта и снова открыть подсказку: счётчик
должен остаться прежним, например 4/5. Затем действительно снять одну часть:
он должен уменьшиться до 3/5. Проверить подсветку четвёртого бонуса.

Проверки на Lua 5.1 покрывают восстановление 4/5, обратную коррекцию,
подсветку порога, красные требования и пропуск чужой экипировки. Настоящий
клиент ещё нужно проверить. Если пропадёт именно эффект бонуса, а не строка
в подсказке, нужен отдельный разбор с названием комплекта и эффектом.
