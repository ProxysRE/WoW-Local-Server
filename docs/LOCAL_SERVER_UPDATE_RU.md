# Общее обновление локального сервера

Этот пакет объединяет текущую версию ядра и Playerbots, гардероб 0.1.1,
бестиарий 0.4.0, сборщик групп AC Group Builder 0.1.0 и команду `.botbuff`.
Сохранены AutoBalance, Individual Progression с временными этапами, AHBot,
телепортер, перековка, профессии, QoL, арена и исправления движения ботов.
Версии ядра и Playerbots в этом обновлении не меняются.

Использовать архив `WoW-Local-Server-Update-x64-N` только из успешного запуска
Windows server build. Полный архив сервера для обновления не требуется.

## Установка

1. Остановить worldserver и authserver. Сохранить резервные копии четырёх баз
   через Navicat. MySQL оставить работающим.
2. Полностью распаковать обновление в отдельную папку. Из неё выполнить,
   подставив путь к своему существующему Server:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install-Update.ps1 -ServerPath 'D:\YourServer\Server'
```

Установщик сохраняет активные .conf и резервирует заменяемые файлы. Он не
подключается к MySQL и не запускает сервер. Каталоги Source объединяются с
существующими; базы и персонажи не заменяются. Резервирование файлов не заменяет
резервные копии баз. Сборщик и BotBuff не требуют новых SQL или конфигов.

3. Из `Client/Interface/AddOns` скопировать в Interface/AddOns игрового клиента
   папки ACWardrobe, WoWBestiary и ACGroupBuilder с заменой файлов. Клиент закрыть
   перед копированием. WTF не удалять: там сохраняются наряды и шаблоны.
4. Запустить сервер привычными BAT-файлами. Встроенный updater пропустит ранее
   применённые миграции. При ошибке сохранить лог; вручную полный дамп не импортировать.
5. Войти в игру и включить три аддона. Для сохранения трансмога по слотам остаётся
   нужен EnablePlayerSettings = 1 в текущем worldserver.conf; установщик его не меняет.

## Первые проверки

- `/гардероб`: старая коллекция и правильный счётчик частей сета.
- `/wb`: бестиарий, фильтры качества и карта выбранного редкого существа,
  если для него доступен запрос текущей позиции. Подробности — BESTIARY_RU.md.
- `/сбор`: предложить группу на пять, проверить свой слот и строгое место
  ДД → маг → тайная магия. Затем закрепление, ручная замена и приглашения.
- Выделить дружественного свободного паладина рядом и нажать макрос:

```
/s .botbuff
```

При необходимости — `/s .botbuff might` (также kings, wisdom, sanctuary).
Команда не приглашает бота в группу. Подробности — BOT_BUFF_RU.md.

Полная инструкция сборщика — GROUP_BUILDER_RU.md; гардероба — WARDROBE_RU.md.
Новые функции требуют игрового прогона после успешной компиляции. Присылайте
ошибку аддона или соответствующий фрагмент лога при сбое.
