# Стартовые профессии

Модуль для закреплённой версии Playerbot-ядра из `sources.lock.json`.
При первом входе нового персонажа игрока изучает 11 основных профессий и
кулинарию, первую помощь, рыбалку. Начальная ступень — 1/75; расовые бонусы
отображаются дополнительно. Стартовые рецепты выдаёт обычная механика ядра.
Новые ступени и остальные рецепты изучаются обычным способом.

Инструменты: кирка (2901), нож для снятия шкур (7005), кузнечный молот (5956),
удочка (6256). По одному экземпляру. Инструмент, уже имеющийся в сумках,
экипировке или банке, повторно не выдаётся. Если сумки полны, инструмент
приходит письмом. Реагенты, рунические жезлы и профессиональные станки не выдаются.

## Установка

Скрипт `scripts/prepare-sources.py` сам копирует модуль в
`core/modules/mod-starter-professions` перед компиляцией. Для отдельной установки
скопируйте туда эту папку и пересоберите worldserver обычным способом.
SQL-импорт и изменения клиента не нужны. Один конфигурационный файл без
перекомпиляции модуль не устанавливает.

В действующем `Server/configs/worldserver.conf` найдите существующую настройку
и установите (не добавляйте вторую строку с тем же именем):

```ini
MaxPrimaryTradeSkill = 11
```

Если уже стоит 13, этого достаточно; вторичные профессии в лимит не входят.
Скопируйте установленный `starter_professions.conf.dist` в
`Server/configs/modules/starter_professions.conf`, сохранив папку, в которую
сборка установила файл. Модуль включён по умолчанию. Для отключения:

```ini
StarterProfessions.Enable = 0
```

Перезапустите worldserver. При обновлении сервера сохраните свои существующие
конфигурации, базы и Data; не запускайте настройку нового сервера поверх них.

## Границы поведения

- Работает только при первом входе (`AT_LOGIN_FIRST`), не изменяет старых персонажей.
- Headless-сессии Playerbots пропускаются, в том числе при ещё не созданном AI.
- Персонаж, созданный вручную для последующего использования как altbot,
  получит набор, если впервые войти на него обычным клиентом.
- Уже изученные профессии, уровни навыков и рецепты сохраняются.
- После отказа от профессии повторный вход её не возвращает.
- При выключенном модуле первый вход расходуется как обычно: последующее
  включение не выдаёт набор задним числом.
- При лимите основных профессий ниже 11 выдача пропускается с сообщением
  и записью в логе. Установите правильный лимит до создания персонажей.

## Проверка в игре

Создайте обычного персонажа первого уровня: все 14 профессий должны появиться
в окне навыков, стартовые рецепты — в соответствующих окнах, четыре инструмента —
в сумке. Проверьте сбор травы, руды, снятие шкур и создание стартового рецепта.
Затем перезайдите: новых инструментов появляться не должно. На старом персонаже
и на автоматически вошедших ботах выдачи быть не должно.
